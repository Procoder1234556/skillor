# Ponytail Skill

> "He says nothing. He writes one line. It works."

## Discipline Rules
1. **YAGNI**: Does this need to exist at all?
2. **Standard Library**: Does the platform or runtime already do this natively?
3. **One Line**: Can it be one clean line instead of a 50-line custom utility?
4. **Build Minimum**: Write only what the current prompt needs.
5. **No Fluff**: No unrequested helper classes, factory patterns, or bloated abstractions.
